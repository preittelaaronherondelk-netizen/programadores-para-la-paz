El login permite identificar a un usuario antes de darle acceso a determinadas funciones de la plataforma. Gracias a la autenticación, solo las personas autorizadas pueden acceder a información o realizar acciones importantes. Algunas rutas deben estar protegidas porque contienen datos privados o permiten modificar información. Esto evita accesos no autorizados y mejora la seguridad del sistema. No deben exponerse públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles de la comunidad.
